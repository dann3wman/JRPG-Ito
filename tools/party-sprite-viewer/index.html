The standard art set for each party member: a 54-frame battle and field sheet and 12 state portraits. Built by the party-art skill. The animation editor changes the standard set every party member shares; export it and apply it with party_art.py anims.

Apply to the repository

Edits are kept in this browser until you reset them. To make them the standard, download the set and run:

python3 .claude/skills/party-art/scripts/party_art.py anims party-anims.json

It checks every animation and effect, writes references/anims.json and references/fx.json, and rebuilds manifest.js. The standard animations can be changed but not deleted, because the game plays them by name.
