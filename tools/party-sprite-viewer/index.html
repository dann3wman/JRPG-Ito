Edits are kept in this browser until you reset them. To make them the standard, download the set and run:

python3 .claude/skills/party-art/scripts/party_art.py anims party-anims.json

It checks every animation and skill, writes references/anims.json and references/skills.json, and rebuilds manifest.js. The standard animations can be changed but not deleted, because the game plays them by name.
